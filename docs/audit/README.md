## 2. Исчерпывающее сравнение декодеров — следующий шаг

Встроенные слова `fift` `(vmoplen)` и `(vmopdump)` (их использует `Disasm.fif`) обращаются
напрямую к таблице диспетчеризации C++. Значит, декодер C++ можно опросить на любом коде без
разбора исходников:

1. Для каждого 16-битного префикса (65 536) — длина инструкции и её запись по C++ и по модели
   (`decodeCp0WithBits`), с одинаковыми хвостовыми битами.
2. Где опкод длиннее 16 бит — перебрать следующие 8 бит.
3. Сравнить длину (биты и ссылки) и мнемонику (через таблицу соответствия форматов записи).

**Готово, когда:** на всём пространстве опкодов длина и инструкция совпадают; список расхождений пуст
или каждое внесено в план.
