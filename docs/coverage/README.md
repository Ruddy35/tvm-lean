# Покрытие C++ при сверке (фаза 2)

Цель фазы 2 — измеримое «один в один»: каждая ветвь C++-кода VM, исполняемая при обработке
транзакции, должна быть пройдена хотя бы одним тестом, сверяющим модель с C++.

## Как измеряется

- `scripts/build-cpp-coverage.sh` — эталонный `fift` (`ton` @ `3d478cb`) собирается с `--coverage -O0`
  в `~/ws/ton-build-cov`; инструменты сборки ставятся локально, без root.
- Сборка с покрытием ведёт себя как эталонный бинарник: полный оракул через неё — 25 777 / 25 777
  на версиях 13 и 16, unit-тесты 5967 / 5967.
- Прогоны сверки с `TON_FIFT_BIN` на эту сборку накапливают счётчики; `scripts/cpp-coverage-report.sh`
  строит отчёт по `crypto/vm`.
