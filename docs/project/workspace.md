# Рабочее пространство

## Сервер сборки и сверки

Все сборки Lean и прогоны сверки — на сервере, все ядра (`lake` параллелит сам, проверка отдельного
файла — `lake env lean -j $(nproc)`).

| Путь | Что |
|---|---|
| `~/ws/tvm-lean` | этот репозиторий (рабочая копия, сборки) |
| `~/ws/ton-src` | исходники C++ эталонного коммита (`3d478cb`, неглубокий клон) |
| `~/ws/ton-bin` | `fift`/`fiftx` эталонного коммита и библиотека `fift` |
| `~/ws/fixtures` | наборы дифференциальных фикстур |
| `~/ws/runs` | логи прогонов |

## Полная сверка

```sh
cd ~/ws/tvm-lean
TON_FIFT_BIN=~/ws/ton-bin/fiftx TON_FIFT_LIB=~/ws/ton-bin/lib FIXTURES=~/ws/fixtures \
  OUT=~/ws/runs/$(date +%F-%H%M) scripts/verify-all.sh
```
