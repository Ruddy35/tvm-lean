# Формальная модель TVM на Lean 4

## Глобальная цель

Полная формальная модель виртуальной машины TON (TVM) на Lean 4, повторяющая C++-реализацию
один в один, и на её основе — проверка любого смарт-контракта по байткоду на инварианты методом
индукции.

Две стадии, строго по порядку:

1. **Полная модель.** Всё, что исполняется при обработке транзакции, переписано на Lean: декодер,
   инструкции, ячейки, словари, арифметика, газ, исключения, продолжения, экзотические ячейки,
   криптография и хэши, фазы транзакции. Учитываются все глобальные версии, которые поддерживает
   эталонный релиз C++. Совпадение с C++ подтверждается полномасштабной сверкой.
2. **Индукция и инварианты.** Общая теорема: если начальное состояние удовлетворяет инварианту и
   каждая транзакция его сохраняет, инвариант верен всегда. Плюс автоматическое символьное исполнение
   байткода с доказанной корректностью, которое сводит проверку любого контракта к условиям для
   решателей.

## Принципы

- **Эталон — C++ конкретного коммита.** Сейчас `ton-blockchain/ton` @ `3d478cb` (на нём собран
  оракул). Каждое поведение модели обосновано ссылкой на код C++ этого коммита.
- **«Один в один» измеряется.** Сверка с C++ — unit-тесты, оракул по всем инструкциям на нескольких
  глобальных версиях, дифференциальные прогоны реального байткода, затем замер покрытия ветвей C++.
- **Модель тотальна.** Никаких `partial`, `sorry`, `admit`, внешних функций в итоговой модели.
- **Изменения модели доказуемо не меняют поведение** там, где это рефакторинг: равенство исходному
  определению доказывается в `TvmLean/Proofs/ModelEquiv.lean`.
- **Каждое изменение — отдельный коммит** с объяснением и ссылкой на C++.
